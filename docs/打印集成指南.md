# 卡片打印集成指南

## 概述

本文档说明 luo.dangxiao 系统中卡面打印的配置与工作原理。打印由 `CardOperationViewModelBase.PrintCardAsync` 统一调度，通过 config.json 驱动。

## 配置

在 `config.json` 的 `PrinterConfig` 节点中配置：

```json
{
  "PrinterConfig": {
    "Provider": "Seaory",
    "DefaultPrinterId": "Seaory S22K",
    "PrintText": [
      {
        "PropertyName": "Name",
        "BodyFont": "微软雅黑",
        "BodySize": 10,
        "X": 200,
        "Y": 430
      },
      {
        "PropertyName": "ClassName",
        "BodyFont": "微软雅黑",
        "BodySize": 10,
        "X": 100,
        "Y": 500
      }
    ],
    "Seaory": {
      "RibbonType": 1,
      "Orientation": 1
    }
  }
}
```

### PrintText 元素

每个元素定义卡面上的一个文本字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `PropertyName` | string | `UserInfoModel` 上的属性名（如 `Name`、`ClassName`、`Department`） |
| `BodyFont` | string | 字体名称，如 `"微软雅黑"`、`"Arial"` |
| `BodySize` | int | 字号（默认 12） |
| `X` | int | 像素级 X 坐标 |
| `Y` | int | 像素级 Y 坐标 |

**注意**：`PropertyName` 必须在 `UserInfoModel` 或其子类（`StudentInfoModel` / `StaffInfoModel`）中存在对应属性，否则该字段会被静默跳过。

### Seaory 配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `RibbonType` | byte | 0 | S 系列色带类型：0=YMCKO, 1=K, 2=1/2ymcKO, 3=YMCKOK |
| `Orientation` | byte | 1 | 方向：1=纵向, 2=横向 |
| `InputBin` | byte? | null | 进纸口：0=卡箱, 1=前手动口, 2=后手动口 |
| `OutputBin` | byte? | null | 出纸口：0=出卡口, 1=前手动口, 2=后手动口, 3=废卡箱 |
| `CardInOut` | byte? | null | 1=使用设备默认设置 |

## 工作流程

```
ExecuteCardProcessAsync(cardOperate)
├── MoveCardToReaderAsync()        # 将卡片移动到读卡位置
├── ReadFactoryFixIdAsync()         # 读取卡片物理ID
├── InitCardAsync(factoryFixId)     # 调用 YKT API 初始化卡片
├── WriteCardAsync(initResult)      # 写入卡片数据
├── PrintCardAsync(initResult)      # 打印卡面文字
│   ├── BeginPrintSession(printerId, seaoryConfig)  # 开始打印会话
│   └── for each PrintTextConfig:                   # 按配置打印文本
│       └── session.PrintText(x, y, text, font, size)
│   └── session.EndPage()           # 结束页面
│   └── session.Dispose()           # 结束打印（触发 SOY_PR_EndPrinting2）
├── MoveToFront                      # 将卡片移动到前出卡口
└── StartPickupMonitor               # 启动取卡倒计时监控
```

## 错误处理

打印失败时，错误码会通过 `CardPrinterBase.LastErrorCode` 和 `LastErrorMsg` 传递到 UI 层显示。

常见 Seaory 错误码：

| 错误码 | 含义 |
|--------|------|
| 0 | 成功 |
| 0x00010021 | 打印机盖打开 |
| 0x00010023 | 废卡箱已满 |
| 0x00010041 | 色带用尽 |
| 0x00010042 | 色带错误 |
| 0x00010043 | 未安装色带 |
| 0x00010051 | 卡片进给错误 |
| 0x0001005F | 无卡片 |
| 0x00011006 | 磁条编码失败 |

## Seaory DocProp

打印会话通过 `BeginPrintSession(printerId, docProp, seaoryConfig)` 构造 `SeaoryDocProp` 对象。优先级：
1. 显式传入的 `docProp`
2. 从 `config.json` 的 `Seaory` 配置构造
3. 仅设置 Orientation=1、RibbonType=0、AutoDetectRibbon=1、CardInOutByDev=1
